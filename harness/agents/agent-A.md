## 참조 스킬

- `skills/domain-skill-N/skill.md` — [이 스킬에서 가져오는 것]

## 입력 명세

이전 에이전트 또는 오케스트레이터로부터 받는 것:

```
FROM: [보내는 주체]
PAYLOAD:
  - [필드명]: [타입/설명]
  - [필드명]: [타입/설명]
```

포맷 상세는 `contracts/messages.md` 참조.

## 산출물 포맷

`_workspace/0N_[산출물명].md` 파일로 저장한다:

```markdown
# [산출물 제목]

## [섹션 1]
[내용 구조 설명]

## [섹션 2]
[내용 구조 설명]
```

## 출력 명세

다음 에이전트에게 전달하는 것:

```
TO: [받는 주체]
PAYLOAD:
  - output_file: _workspace/0N_[산출물명].md
  - summary: [핵심 내용 요약 — 3줄 이내]
  - blockers: [다음 에이전트가 반드시 알아야 할 제약/가정]
```

포맷 상세는 `contracts/messages.md` 참조.
