# 리뷰 판단 기준

reviewer 에이전트가 산출물을 평가할 때 사용하는 기준을 정의한다.
모든 판단은 주관이 아닌 이 파일의 기준에 근거해야 한다.

---

## 심각도 분류

### 🔴 필수 수정 (블로킹)

다음 조건 중 하나라도 해당하면 🔴를 발행한다:

- [ ] [기준 1: 예 — 필수 섹션이 누락된 경우]
- [ ] [기준 2: 예 — 이전 산출물과 명백히 충돌하는 내용이 있는 경우]
- [ ] [기준 3: 예 — 에이전트 정의의 산출물 포맷을 따르지 않은 경우]
- [ ] [도메인 특화 기준 추가]

🔴가 하나라도 있으면 최종 PASS 불가. 수정 완료 후 재검증 필수.

### 🟡 권장 수정 (논블로킹)

다음 조건에 해당하면 🟡를 발행한다. 진행은 가능하나 개선 권고:

- [ ] [기준 1: 예 — 내용이 기준치보다 빈약하나 구조는 갖춘 경우]
- [ ] [기준 2: 예 — 일관성이 다소 부족하나 치명적이지 않은 경우]
- [ ] [도메인 특화 기준 추가]

### ⚪ 참고 사항

판단에 영향을 주지 않으나 향후 개선을 위해 기록:

- [예: 다음 버전에서 고려할 확장 아이디어]
- [예: 현재 범위 밖이지만 관련된 참고 정보]

## 재검증 루프 규칙

- 🔴 수정 요청 후 재검증 최대 횟수: **2회**
- 2회 초과 시: 미해소 🔴 목록을 보고서에 명시하고 오케스트레이터에 에스컬레이션
- 🟡는 재검증 루프를 트리거하지 않는다

## 최종 판정 기준

| 판정 | 조건 |
|------|------|
| PASS | 🔴 0건 |
| PASS with warnings | 🔴 0건, 🟡 1건 이상 |
| FAIL | 🔴 1건 이상 |
