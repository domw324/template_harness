## 워크플로우

### Phase 1: 준비 (오케스트레이터 직접 수행)

1. 사용자 입력에서 추출한다:
   - **[필수 입력 1]**: [설명]
   - **[필수 입력 2]**: [설명]
   - **[선택 입력]**: [설명, 없을 경우 기본값 명시]
2. `_workspace/` 디렉토리를 생성한다
3. 입력을 정리하여 `_workspace/00_input.md`에 저장한다
4. 기존 파일이 있으면 `_workspace/`에 복사하고 해당 Phase를 건너뛴다
5. 요청 범위에 따라 실행 모드를 결정한다 (아래 "작업 규모별 모드" 참조)

### Phase 2: 에이전트 실행

| 순서 | 작업 | 담당 에이전트 | 의존 | 산출물 |
|------|------|------------|------|--------|
| 1 | [작업명] | agent-A | 없음 | `_workspace/01_[산출물].md` |
| 2a | [작업명] | agent-B | 작업 1 | `_workspace/02_[산출물].md` |
| 2b | [작업명] | agent-C | 작업 1 | `_workspace/03_[산출물].md` |
| 3 | 검증 | reviewer | 작업 2a, 2b | `_workspace/99_review.md` |

> 작업 2a, 2b는 **병렬 실행** 가능 — 둘 다 작업 1에만 의존한다.

**에이전트 간 소통 흐름:**

- agent-A 완료 → agent-B, agent-C에게 SendMessage (포맷: `contracts/messages.md` 참조)
- agent-B, agent-C 완료 → reviewer에게 완료 신호 전달
- reviewer 🔴 발견 시 → 해당 에이전트에 수정 요청 → 재작업 → 재검증

### Phase 3: 마무리

1. `_workspace/99_review.md`의 🔴 항목이 모두 해소되었는지 확인한다
2. 사용자에게 최종 산출물 목록을 보고한다
